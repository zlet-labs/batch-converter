Zlet Batch Converter v0.0.2
================================

Архив: ZletBatchConverter-v0.0.2-win-x64.zip

1. Полностью распакуйте ZIP в обычную локальную папку.
2. Запустите ZletBatchConverter.exe.
3. Не отделяйте ZletBatchConverter.exe от остальных файлов распакованной папки.

Приложение работает локально и не отправляет документы в интернет.
.NET 8 входит в self-contained пакет.

Для преобразования нужны установленные приложения:
- DOC -> DOCX: Microsoft Word;
- XLS -> XLSX: Microsoft Excel;
- PPT -> PPTX: Microsoft PowerPoint.

Каждое приложение необязательно и влияет только на свой формат. Например, если
PowerPoint отсутствует, DOC и XLS по-прежнему можно обрабатывать при наличии
Word и Excel.

Если PowerPoint уже запущен, преобразование PPT не начинается: закройте
PowerPoint и повторите попытку. DOC, XLS и копирование PPTX не блокируются.

DOCX, XLSX и PPTX можно безопасно копировать без повторного преобразования и без
установленного Office. JSON можно преобразовать в TXT или Markdown.

Microsoft Office не входит в комплект. Python и Java не используются.
Оригинальные файлы открываются только для чтения и проверяются по SHA-256.
Существующие результаты не перезаписываются.

Сложные, повреждённые, защищённые паролем или несовместимые документы могут не
преобразоваться. Перед рабочим использованием проверьте результат вручную.
