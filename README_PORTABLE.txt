Zlet Batch Converter — PRE-ALPHA · v0.0.0 — portable Windows x64
=================================================================

Назначение
----------
Локальное массовое преобразование файлов по правилам. Файлы не отправляются в
интернет. Оригиналы не перезаписываются, не удаляются и не перемещаются.

Запуск
------
1. Полностью распакуйте ZletBatchConverter-v0.0.0-win-x64.zip.
2. Не отделяйте ZletBatchConverter.exe от папки runtime\libreoffice.
3. Запустите ZletBatchConverter.exe без прав администратора.
4. Введите, вставьте или выберите исходную папку и нажмите «Найти файлы».
5. Настройте правила и выберите операции checkbox-ами или bulk-командами.
6. Выберите режим результата «Папка» или «ZIP-архив» и укажите путь.
7. Запустите преобразование и проверьте итоговый отчёт.

Folder mode сохраняет структуру подпапок в выбранной output-папке. ZIP mode
включает только успешно созданные выбранные результаты. Существующие targets и
ZIP не перезаписываются; при нуле успешных результатов пустой ZIP не создаётся.

Отдельная установка .NET Runtime, Microsoft Office или LibreOffice не нужна.

Ограничения
-----------
Сложное визуальное форматирование после LibreOffice-конвертации может
отличаться; pixel-perfect совместимость не гарантируется. XLSX -> CSV по листам
не входит в ZL-041. PDF и изображения не преобразуются.

Лицензии и версия bundled LibreOffice находятся в папке licenses.
Проверенная конфигурация: LibreOffice 26.2.4.2, официальный Windows x86-64
package; 15 mappings DOC/XLS/PPT, DOCX/XLSX/PPTX и ODT/ODS/ODP.

Это pre-alpha candidate, не опубликованный public release. Перед публикацией
требуется отдельная проверка на чистой Windows-машине или VM.
