Zlet Folder Converter — portable Windows x64
================================================

Назначение
----------
Локальное массовое преобразование смешанных файлов по правилам.
Поддерживаемые направления перечислены в интерфейсе и README.

Запуск
------
1. Полностью распакуйте ZIP в обычную папку.
2. Не перемещайте отдельно ZletFolderConverter.exe: папка
   runtime\libreoffice должна оставаться рядом с приложением.
3. Запустите ZletFolderConverter.exe без прав администратора.
4. Выберите папку, нажмите «Найти файлы» и настройте правила.
5. Проверьте preview и нажмите «Преобразовать N файлов».
6. Результаты находятся в корневой папке _converted.

Отдельная установка .NET Runtime, Microsoft Office или LibreOffice не нужна.
Приложение не использует cloud conversion и не отправляет файлы в интернет.

Гарантии
--------
- оригиналы не перезаписываются, не удаляются и не перемещаются;
- существующие target-файлы и директории не заменяются;
- структура подпапок сохраняется;
- ошибка одного файла не останавливает остальные операции.

Ограничения
-----------
Визуальное форматирование сложных документов может отличаться после
LibreOffice-конвертации. 100% совместимость не гарантируется.
XLSX -> CSV по листам не входит в ZL-041. PDF и изображения не преобразуются.

Лицензии и версия bundled LibreOffice находятся в папке licenses.
