# Zlet Folder Converter

> Локальное пакетное преобразование файлов в Windows с предварительным просмотром, безопасными путями результата и без загрузки в облако.

**Zlet Labs** · **Alpha**

[![Windows](https://img.shields.io/badge/Windows-10%20%7C%2011-2563EB?logo=windows11&logoColor=white)](https://github.com/zlet-labs/folder-converter)
[![.NET](https://img.shields.io/badge/.NET-8-512BD4?logo=dotnet&logoColor=white)](https://dotnet.microsoft.com/)
[![License](https://img.shields.io/badge/License-MIT-22C55E)](LICENSE)

Zlet Folder Converter сканирует выбранную папку, показывает план операций и сохраняет результаты в `<выбранная папка>\_converted`. Исходные файлы не изменяются, не перемещаются, не удаляются и не перезаписываются.

> **Текущий scope alpha:** JSON → TXT и JSON → Markdown. Конвертация старых форматов Microsoft Office в текущей сборке недоступна.

## Что делает программа

- сканирует одну папку или дерево подпапок;
- находит поддерживаемые исходные файлы, не заходя в корневую папку результата `_converted`;
- показывает пути исходника и результата до записи файлов;
- обрабатывает каждый поддерживаемый файл независимо;
- сохраняет относительную структуру подпапок;
- показывает успешные операции, конфликты, неподдерживаемые файлы и ошибки;
- продолжает обработку, если один файл завершился ошибкой.

## Зачем она нужна

В старых папках обычно лежат смешанные форматы, дубликаты и файлы, которые нужно привести к удобному виду перед повторным использованием. Инструмент делает процесс явным и безопасным: выбрать папку, проверить план, преобразовать и забрать результат.

Аккаунт, dashboard, очередь загрузки и облачный сервис не требуются. Мир как-нибудь переживёт отсутствие ещё одного onboarding на семь экранов.

## Поддерживаемые форматы

| Исходник | Результат | Статус |
|---|---|---|
| JSON | TXT | Поддерживается |
| JSON | Markdown | Поддерживается |
| DOC | DOCX | Не поддерживается в текущей alpha |
| XLS | XLSX | Не поддерживается в текущей alpha |
| PPT | PPTX | Не поддерживается в текущей alpha |

Расширения распознаются без учёта регистра. JSON сохраняется в UTF-8 с корректной поддержкой Unicode.

## Текущие ограничения

- только Windows x64;
- DOC, XLS и PPT пока не преобразуются;
- нет XLSX → CSV, PDF-конвертации, OCR и объединения JSON;
- существующие файлы и директории результата считаются конфликтами и не перезаписываются;
- нет установщика, автообновления, ассоциаций файлов, telemetry и cloud sync;
- программа не обещает визуальную идентичность для форматов, конвертация которых не реализована и не проверена.

## Конфиденциальность и безопасность файлов

- обработка выполняется локально;
- файлы не загружаются в сеть;
- оригиналы остаются без изменений;
- результат создаётся только в корневой папке `_converted`;
- существующие пути результата защищены от перезаписи;
- корневая `_converted`, временные Office-файлы и reparse-директории пропускаются при сканировании;
- ошибка изолируется на уровне отдельного файла;
- логи и отчёты не должны содержать содержимое документов, секреты и учётные данные.

Для баг-репортов используйте синтетические или обезличенные файлы. Не прикладывайте в публичные Issues документы клиентов, рабочие документы, финансовые сведения, удостоверения личности или медицинские данные.

## Запуск приложения

Когда появится релиз:

1. Откройте [GitHub Releases](https://github.com/zlet-labs/folder-converter/releases).
2. Скачайте приложенный к релизу portable ZIP для Windows.
3. Полностью распакуйте архив в локальную папку.
4. Запустите `ZletFolderConverter.exe`.
5. Выберите исходную папку, проверьте preview и запустите обработку.
6. Результаты появятся в `_converted` внутри исходной папки.

## Сборка из исходников

Требования:

- Windows 10 или Windows 11 x64;
- .NET 8 SDK;
- PowerShell для сборки portable-пакета.

```powershell
git clone https://github.com/zlet-labs/folder-converter.git
cd folder-converter
dotnet restore FolderConverter.sln
dotnet build FolderConverter.sln -c Release
dotnet test FolderConverter.sln -c Release
powershell -ExecutionPolicy Bypass -File scripts/publish-portable.ps1
```

Portable-артефакты создаются в `artifacts\portable\win-x64` и не коммитятся в Git.
