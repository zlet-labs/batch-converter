# Repository images

This directory is reserved for real Zlet Folder Converter visuals:

- repository banner or social preview;
- application icon;
- current application screenshot;
- optional short GIF demonstrating the real workflow.

## Rules

- Use the public `Zlet Labs` brand only.
- Match the current application build.
- Do not add mock screenshots that show unavailable features.
- Do not expose local user names, absolute paths, document contents, tokens, or customer data.
- Use synthetic files and sanitized paths.
- Prefer deep navy or black backgrounds with restrained violet and blue accents.
- Keep screenshots readable in the GitHub README on desktop and mobile.

A screenshot should be added only after the interface shown in it is available in a reviewed build. Apparently even pixels require acceptance criteria now, which is still better than publishing fiction.
